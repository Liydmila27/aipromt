Для уроков и подготовки

Промт: план урока

Сгенерируй подробный план урока по теме [тема] для [класс] класса. Включи цели, этапы урока, задания для учеников, вопросы для рефлексии и домашнее задание. Уложись в 45 минут.

Сгенерируй подробный план урока по теме «[тема]» для [класс] класса. Цели: образовательные, развивающие, воспитательные. Этапы: организационный момент, актуализация, изучение нового, практика, рефлексия. Добавь 3 разноуровневых задания и 1 вариант домашнего задания. Формат: нумерованный список по минутам.
Промт: объяснение темы

Сделай объяснение темы простым языком для учеников [класс], добавь 2-3 жизненных примера и 3 вопроса для проверки понимания.

Объясни тему «[тема]» так, чтобы понял ученик [класс] класса. Используй не более 3 абзацев. Добавь 2 жизненных примера и 3 вопроса «на понимание» в конце. Тон: дружелюбный, без сложных терминов.
Промт: карточки для повторения

Создай 10 карточек «вопрос-ответ» по теме для быстрой проверки знаний на уроке.

Создай 10 карточек для повторения по теме «[тема]». Формат: «Вопрос: … Ответ: …». Уровень: [класс]. Вопросы должны покрывать ключевые понятия и типичные ошибки. Не используй длинные формулировки.
Промт: дифференцированные задания

Подготовь 3 уровня заданий (базовый, средний, продвинутый) по теме.

Подготовь 3 задания по теме «[тема]»: базовый уровень (для тех, кто только осваивает), средний (для уверенных), продвинутый (для сильных учеников). Для каждого укажи цель, ожидаемый результат и критерии оценивания. Формат: список с подзаголовками.
Промт: рефлексия и обратная связь

Придумай 5 вариантов рефлексии для конца урока и шаблон обратной связи для учеников.

Предложи 5 вариантов короткой рефлексии (1-3 минуты) для конца урока по теме «[тема]». Плюс один шаблон обратной связи от учителя к ученику (3-4 строки). Тон: поддерживающий, конструктивный.
Промт: межпредметная связь

Покажи, как тема связана с другими предметами, и дай 2-3 идеи для мини-проекта.

Покажи связь темы «[тема]» с 2-3 другими предметами (например, литература, биология, история). Дай 3 идеи мини-проектов (по 30-60 минут) для учеников [класс], где эта связь будет полезна. Формат: короткий список с пояснением 1-2 предложения.

Для методической работы

Промт: самоанализ урока

Помоги провести самоанализ урока: сильные стороны, зоны роста, идеи на следующий урок.

Проведи самоанализ урока по теме «[тема]», [класс], длительность 45 минут. Выдели 3 сильные стороны, 3 зоны роста и 3 идеи на следующий урок. Формат: маркированные списки. Тон: конструктивный, без самокритики.
Промт: тезисы для выступления

Подготовь тезисы для методического выступления на 5-7 минут.

Подготовь тезисы для методического выступления (5-7 минут) на тему «[тема/опыт]» для коллег-учителей. Включи 3 ключевых идеи, 2 примера из практики, 1 вывод. Формат: короткие пункты по 1-2 строки.
